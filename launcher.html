Nous rejoindre

Téléchargez le modpack et connectez-vous

Quelques minutes suffisent pour installer le modpack Cobblemon et rejoindre RonflexCorp.

☕ Java 21

Requis pour Minecraft 1.21.x

🧵 NeoForge

Chargeur de mods utilisé par le modpack

💾 6 Go de RAM

Minimum recommandé pour Cobblemon

🌐 Compte Minecraft Java

Edition Java, pas Bedrock

1

Installez un launcher compatible

Téléchargez et installez CurseForge ou le launcher Modrinth — les deux permettent d'installer des modpacks en un clic.

2

Recherchez et installez le modpack « RonflexCorp »

Dans la recherche du launcher, tapez RonflexCorp puis cliquez sur Installer. Le launcher télécharge automatiquement Minecraft, NeoForge et tous les mods nécessaires (Cobblemon inclus).

3

Lancez le jeu une première fois

Cliquez sur Jouer depuis le launcher. Le premier lancement peut prendre quelques minutes le temps que Minecraft se configure.

4

Ajoutez le serveur et connectez-vous

Dans le menu Multijoueur, cliquez sur Ajouter un serveur et renseignez l'adresse ci-dessous.

Adresse du serveur

Copiez l'IP et collez-la dans votre client Minecraft.

play.ronflexcorp.fr
Besoin d'aide

Questions fréquentes

Le modpack n'apparaît pas dans la recherche

Vérifiez que votre launcher est à jour. Si le modpack reste introuvable, utilisez le lien direct partagé sur notre Discord dans le salon #launcher.

Le jeu crash au lancement

Assurez-vous d'avoir alloué au moins 6 Go de RAM au jeu dans les paramètres du launcher, et que vous utilisez bien Java 21.

Puis-je jouer sur Minecraft Bedrock (mobile / console) ?

Non, Cobblemon est un mod Forge/NeoForge disponible uniquement sur l'édition Java de Minecraft.

J'ai un autre problème de connexion

Passez par le salon #support de notre Discord, un membre de l'équipe vous répondra rapidement.
